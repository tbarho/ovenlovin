## Deploy to Vercel

The fastest way to get started is to deploy OvenLovin to Vercel with one click using the button above.

The one-click deploy will:

- Clone the repository to your GitHub account
- Create a new Vercel project
- Provision Neon Postgres, Vercel Blob, and Clerk (auto-configures `DATABASE_URL`, the blob token, and Clerk keys)
- Prompt for AI Gateway, USDA, and an optional instance name
- Run database migrations during the Vercel build
- Deploy the Next.js app

If the Clerk store is not offered, set `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` and `CLERK_SECRET_KEY` in the Vercel project.

### Environment Variables

| Variable | Description | Get It |
|----------|-------------|--------|
| `DATABASE_URL` | Neon Postgres connection string | Auto-configured by the Neon store |
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | Clerk publishable key | Auto-configured by the Clerk store, or [clerk.com](https://clerk.com) |
| `CLERK_SECRET_KEY` | Clerk secret key | Auto-configured by the Clerk store, or [clerk.com](https://clerk.com) |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob storage token | Auto-configured by the Blob store |
| `AI_GATEWAY_API_KEY` | Vercel AI Gateway API key | [vercel.com/ai](https://vercel.com/ai) |
| `USDA_FDC_API_KEY` | USDA FoodData Central API key | [fdc.nal.usda.gov](https://fdc.nal.usda.gov) |
| `NEXT_PUBLIC_INSTANCE_NAME` | Optional landing-page name | Defaults to `Your OvenLovin` |

## Local Development

### Prerequisites

- Node.js 20 or later
- pnpm 9 or later
- PostgreSQL database (or use Neon)

### Installation

<Tabs items={['pnpm', 'npm', 'yarn']}>
  <Tab value="pnpm">
    ```bash
    # Clone the repository
    git clone https://github.com/tbarho/ovenlovin.git
    cd ovenlovin

    # Install dependencies
    pnpm install

    # Set up environment variables
    cp .env.example .env.local
    # Edit .env.local with your API keys

    # Run database migrations
    pnpm --filter @ovenlovin/db migrate

    # Start development server
    pnpm dev
    ```
  </Tab>
  <Tab value="npm">
    ```bash
    # Clone the repository
    git clone https://github.com/tbarho/ovenlovin.git
    cd ovenlovin

    # Install dependencies
    npm install

    # Set up environment variables
    cp .env.example .env.local
    # Edit .env.local with your API keys

    # Run database migrations
    npm run --workspace @ovenlovin/db migrate

    # Start development server
    npm run dev
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    # Clone the repository
    git clone https://github.com/tbarho/ovenlovin.git
    cd ovenlovin

    # Install dependencies
    yarn install

    # Set up environment variables
    cp .env.example .env.local
    # Edit .env.local with your API keys

    # Run database migrations
    yarn workspace @ovenlovin/db migrate

    # Start development server
    yarn dev
    ```
  </Tab>
</Tabs>

The app will be available at `http://localhost:3000`.
