## Deploy to Vercel

The fastest way to get started is to deploy OvenLovin to Vercel with one click:

[Deploy to Vercel →](https://vercel.com/new/clone?repository-url=https://github.com/tbarho/ovenlovin)

The one-click deploy will:

- Clone the repository to your GitHub account
- Create a new Vercel project
- Connect a Neon Postgres database (auto-configured `DATABASE_URL`)
- Prompt for required API keys and secrets
- Deploy the Next.js app with all environment variables

### Required Environment Variables

You'll need to obtain API keys for the following services:

| Variable | Description | Get It |
|----------|-------------|--------|
| `DATABASE_URL` | Neon Postgres connection string | Auto-configured with Neon integration |
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | Clerk publishable key | [clerk.com](https://clerk.com) |
| `CLERK_SECRET_KEY` | Clerk secret key | [clerk.com](https://clerk.com) |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob storage token | [vercel.com/storage](https://vercel.com/storage) |
| `AI_GATEWAY_API_KEY` | Vercel AI Gateway API key | [vercel.com/ai](https://vercel.com/ai) |
| `USDA_FDC_API_KEY` | USDA FoodData Central API key | [fdc.nal.usda.gov](https://fdc.nal.usda.gov) |

## Local Development

### Prerequisites

- Node.js 20 or later
- pnpm 9 or later
- PostgreSQL database (or use Neon)

### Installation

#### Using pnpm

```bash
# Clone the repository
git clone https://github.com/tbarho/ovenlovin.git
cd ovenlovin

# Install dependencies
pnpm install

# Set up environment variables
cp .env.example .env.local
# Edit .env.local with your API keys

# Run database migrations
pnpm --filter @ovenlovin/db migrate

# Start development server
pnpm dev
```

The app will be available at `http://localhost:3000`.

### Development Commands

```bash
# Run all workspaces in dev mode
pnpm dev

# Run specific workspace
pnpm --filter @ovenlovin/web dev
pnpm --filter @ovenlovin/core test:watch

# Build
pnpm build

# Test
pnpm test
pnpm test:watch

# Lint & format
pnpm lint
pnpm format
pnpm typecheck

# Clean
pnpm clean
```
