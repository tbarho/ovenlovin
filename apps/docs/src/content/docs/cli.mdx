The OvenLovin CLI provides a command-line interface for importing recipes, managing meal plans, and running allergy checks without a web browser.

> **Note:** The CLI package (`@ovenlovin/cli`) is currently in development. This documentation describes the planned interface.

## Installation

### Global Install

```bash
pnpm add -g @ovenlovin/cli
```

### Project Install

```bash
pnpm add -D @ovenlovin/cli
```

### npx (No Install)

```bash
npx @ovenlovin/cli [command]
```

## Configuration

The CLI reads configuration from:

1. Environment variables
2. `.env` or `.env.local` file
3. Command-line flags

### Required Environment Variables

```bash
# Database connection
DATABASE_URL=postgresql://user:pass@host:5432/ovenlovin

# Authentication
OVENLOVIN_API_KEY=olvn_key_...

# Optional: AI features
AI_GATEWAY_API_KEY=...
BLOB_READ_WRITE_TOKEN=...
```

### Config File

Create `ovenlovin.config.json` in your project root:

```json
{
  "apiUrl": "https://your-app.vercel.app",
  "householdId": "household_...",
  "defaultServings": 4
}
```

## Commands

### `import`

Import recipes from URLs, files, or text.

#### Import from URL

```bash
# Import single recipe
ovenlovin import url https://example.com/recipe/chocolate-chip-cookies

# Import multiple recipes
ovenlovin import url \
  https://example.com/recipe/cookies \
  https://example.com/recipe/brownies

# Save to specific household
ovenlovin import url https://example.com/recipe --household household_123
```

#### Import from File

```bash
# Import from JSON
ovenlovin import file recipe.json

# Import from text file
ovenlovin import paste recipe.txt

# Import from image (OCR)
ovenlovin import photo recipe-card.jpg
```

#### Import from Stdin

```bash
# Pipe text
cat recipe.txt | ovenlovin import paste -

# Paste from clipboard (macOS)
pbpaste | ovenlovin import paste -
```

#### Options

- `--household <id>` - Target household ID
- `--dry-run` - Preview without saving
- `--format <json|yaml|table>` - Output format
- `--confidence-threshold <0-1>` - Minimum confidence to accept (default: 0.5)

### `recipes`

List and search recipes.

```bash
# List all recipes
ovenlovin recipes list

# Search by keyword
ovenlovin recipes search "chocolate"

# Filter by cuisine
ovenlovin recipes list --cuisine italian

# Show recipe details
ovenlovin recipes show recipe_123

# Export recipe
ovenlovin recipes export recipe_123 --format json > recipe.json
```

#### Options

- `--household <id>` - Filter by household
- `--limit <n>` - Number of results (default: 20)
- `--format <json|yaml|table>` - Output format
- `--cuisine <name>` - Filter by cuisine
- `--course <name>` - Filter by course (appetizer, main, dessert, etc.)
- `--max-cook-time <minutes>` - Filter by cook time

### `plan`

Create and manage meal plans.

```bash
# Create weekly meal plan
ovenlovin plan create --start 2024-01-15 --days 7

# Add recipe to plan
ovenlovin plan add plan_123 recipe_456 --date 2024-01-15 --meal dinner

# Show plan
ovenlovin plan show plan_123

# Check for allergen conflicts
ovenlovin plan check plan_123

# Export shopping list
ovenlovin plan shopping plan_123 --format markdown > shopping-list.md
```

#### Options

- `--household <id>` - Target household
- `--start <date>` - Plan start date (YYYY-MM-DD)
- `--days <n>` - Number of days (default: 7)
- `--format <json|yaml|table|markdown>` - Output format
- `--attendees <id,id,...>` - Person IDs for meal plan

### `check`

Run allergy and dietary restriction checks.

```bash
# Check single recipe
ovenlovin check recipe recipe_123

# Check meal plan
ovenlovin check plan plan_456

# Check recipe for specific people
ovenlovin check recipe recipe_123 --people person_1,person_2

# Show detailed findings
ovenlovin check recipe recipe_123 --verbose
```

#### Output

```
Checking recipe: Peanut Butter Cookies (recipe_123)
Attendees: 3 people

❌ BLOCK (1)
  - Parent A: recipe contains peanut butter (block rule for peanuts)

⚠️  WARN (0)

ℹ️  PREFER-AVOID (1)
  - Child B: recipe contains gluten (prefer_avoid rule)

✅ SAFE for 1 person
```

### `household`

Manage household and people.

```bash
# List households
ovenlovin household list

# Show household details
ovenlovin household show household_123

# Add person
ovenlovin household add-person \
  --name "Parent A" \
  --household household_123

# Add dietary rule
ovenlovin household add-rule \
  --person person_123 \
  --kind allergen \
  --value peanuts \
  --severity block \
  --reason "Severe peanut allergy"

# List people and rules
ovenlovin household people household_123
```

### `sync`

Sync data between instances.

```bash
# Export household data
ovenlovin sync export household_123 --output backup.json

# Import household data
ovenlovin sync import backup.json

# Sync to another instance
ovenlovin sync push \
  --source http://localhost:3000 \
  --target https://prod.example.com \
  --household household_123
```

## Global Flags

Available for all commands:

- `--help, -h` - Show help
- `--version, -v` - Show version
- `--api-url <url>` - Override API URL
- `--api-key <key>` - Override API key
- `--format <format>` - Output format (json, yaml, table)
- `--quiet, -q` - Suppress non-error output
- `--verbose` - Show detailed output
- `--no-color` - Disable colored output

## Output Formats

### JSON

```bash
ovenlovin recipes show recipe_123 --format json
```

```json
{
  "id": "recipe_123",
  "title": "Chocolate Chip Cookies",
  "ingredients": [
    {
      "name": "flour",
      "quantity": { "min": 2.25 },
      "unit": "cups"
    }
  ]
}
```

### YAML

```bash
ovenlovin recipes show recipe_123 --format yaml
```

```yaml
id: recipe_123
title: Chocolate Chip Cookies
ingredients:
  - name: flour
    quantity:
      min: 2.25
    unit: cups
```

### Table

```bash
ovenlovin recipes list --format table
```

```

```

## Examples

### Import and Plan Workflow

```bash
# 1. Import recipes
ovenlovin import url https://example.com/recipe/pasta
ovenlovin import url https://example.com/recipe/salad

# 2. Create meal plan
PLAN_ID=$(ovenlovin plan create --start 2024-01-15 --days 7 --format json | jq -r '.id')

# 3. Add recipes to plan
ovenlovin plan add $PLAN_ID recipe_pasta --date 2024-01-15 --meal dinner
ovenlovin plan add $PLAN_ID recipe_salad --date 2024-01-16 --meal lunch

# 4. Check for allergen conflicts
ovenlovin plan check $PLAN_ID

# 5. Generate shopping list
ovenlovin plan shopping $PLAN_ID --format markdown > shopping.md
```

### Batch Import

```bash
# Import all recipes from a file list
cat recipe-urls.txt | while read url; do
  ovenlovin import url "$url" --quiet
done

# Or use xargs for parallel imports
cat recipe-urls.txt | xargs -P 4 -I {} ovenlovin import url {}
```

### CI/CD Integration

```bash
#!/bin/bash
# Recipe quality check in CI

# Import recipe from PR
RECIPE_ID=$(ovenlovin import url $RECIPE_URL --dry-run --format json | jq -r '.id')

# Check confidence score
CONFIDENCE=$(ovenlovin recipes show $RECIPE_ID --format json | jq -r '.confidence.overall')

if (( $(echo "$CONFIDENCE < 0.7" | bc -l) )); then
  echo "❌ Recipe confidence too low: $CONFIDENCE"
  exit 1
fi

echo "✅ Recipe passed quality check"
```

## Authentication

### API Key

Generate an API key in the OvenLovin web dashboard:

1. Sign in to your instance
2. Go to **Settings** → **API Keys**
3. Click **Create API Key**
4. Copy the key (starts with `olvn_key_...`)

Set as environment variable:

```bash
export OVENLOVIN_API_KEY=olvn_key_...
```

Or pass via flag:

```bash
ovenlovin recipes list --api-key olvn_key_...
```

### Service Account

For automated workflows, create a service account:

```bash
# Create service account (web UI)
# Then use its API key
export OVENLOVIN_API_KEY=olvn_key_svc_...
```

## Troubleshooting

### Connection Errors

```bash
# Test API connectivity
curl https://your-app.vercel.app/api/health

# Check API key
ovenlovin household list --verbose
```

### Import Failures

```bash
# Use dry-run to preview
ovenlovin import url https://example.com/recipe --dry-run

# Check confidence threshold
ovenlovin import url https://example.com/recipe --confidence-threshold 0.3

# View detailed errors
ovenlovin import url https://example.com/recipe --verbose
```

### Database Connection

```bash
# Verify DATABASE_URL
echo $DATABASE_URL

# Test connection
psql $DATABASE_URL -c "SELECT 1"
```
