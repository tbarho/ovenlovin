---
title: get_meal_plan
description: Retrieve a saved meal plan by ID or date range
---

Get a saved meal plan with enriched recipe details, attendee information, and check report summary. Use to retrieve existing plans for review or modification.

## Input Schema

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `planId` | string (UUID) | No* | Meal plan ID to retrieve |
| `weekStart` | string (date) | No* | Week start date (YYYY-MM-DD) to find plan for |

*Either `planId` or `weekStart` must be provided.

## Output Schema

```typescript
{
  id: string,
  weekStart: string,
  status: "draft" | "approved" | "archived",
  entries: Array<{
    date: string,
    meal: string,
    recipe: {
      id: string,
      title: string,
      prepTimeMinutes?: number,
      cookTimeMinutes?: number
    },
    servings: number,
    attendees: Array<{
      id: string,
      displayName: string
    }>,
    prepAheadNotes?: string
  }>,
  checkReport?: {
    status: "complete" | "incomplete",
    blockingIssues: number,
    warnings: number,
    checkedAt: string
  },
  acknowledgedWarnings: string[]
}
```

## Example Call (by ID)

```json
{
  "planId": "plan-abc-123"
}
```

## Example Call (by date)

```json
{
  "weekStart": "2024-01-15"
}
```

## Lookup Behavior

### By planId
- Returns exact plan matching the ID
- Throws error if not found
- Fastest lookup method

### By weekStart
- Returns the first plan matching that week start date
- Returns error if no plan exists for that week
- Use when you know the week but not the plan ID

## Usage Notes

1. **Enriched data**: Recipe and attendee details are pre-loaded for display
2. **Check report summary**: The `checkReport` provides high-level safety status; full findings are stored but not returned here
3. **Re-checking**: If the plan status shows `needsRecheck` (not shown in output but stored), re-run `check_meal_plan` before using
4. **Get full recipe details**: Use [get_recipe](/docs/reference/mcp/get-recipe) for complete ingredient lists
