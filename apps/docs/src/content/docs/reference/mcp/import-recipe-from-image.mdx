---
title: import_recipe_from_image
description: Import a recipe from a photo URL or base64 image
---

Import a recipe from a photo (URL or base64). Uses AI Gateway vision. The first image is stored as the single main photo. `save:false` returns a preview; omit `save` to persist. `skipReview` clears `needsReview`. Returns `uncertainFields` when the photo is hard to read.

## Input

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `imageUrl` | string | No | - | Public image or Vercel Blob URL |
| `imageBase64` | string | No | - | Raw base64 or data URL |
| `mimeType` | string | No | - | MIME type when sending raw base64 |
| `images` | array | No | - | Extra pages (`url` or `base64` each). First photo is the main image |
| `isHandwritten` | boolean | No | - | Hint that the card is handwritten |
| `draft` | object | No | - | Previewed recipe from a prior import. Skips extract |
| `save` | boolean | No | persist | `false` returns a preview without saving |
| `idempotencyKey` | string | No | - | Same key replays the same saved recipe |
| `allowDuplicate` | boolean | No | - | Persist a near-duplicate photo instead of returning the existing recipe |
| `skipReview` | boolean | No | `false` | Skip review queue and publish immediately |
| `cookbookId` | string (UUID) | No | - | File the imported recipe in this cookbook |

Provide `imageUrl`, `imageBase64`, `images[]`, or `draft`.

Needs AI Gateway (`AI_GATEWAY_API_KEY` locally; OIDC / `VERCEL=1` on Vercel). Vision model: `RK_MODEL_VISION` or `deepseek/deepseek-v4.1-flash`.

## Example

```json
{
  "imageUrl": "https://blob.vercel-storage.com/recipe-card.jpg",
  "save": false
}
```
