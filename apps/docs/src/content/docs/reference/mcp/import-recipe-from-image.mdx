---
title: import_recipe_from_image
description: Import a recipe from a photo URL or base64 image
---

Import a recipe from a recipe card, cookbook page, screenshot, or several pages of one recipe. Uses a vision-capable model through Vercel AI Gateway. The first photo is stored in Vercel Blob as the recipe's single main image.

## Input Schema

| Parameter       | Type          | Required | Default | Description                                     |
| --------------- | ------------- | -------- | ------- | ----------------------------------------------- |
| `imageUrl`      | string        | No\*     | -       | Public image or Vercel Blob URL                 |
| `imageBase64`   | string        | No\*     | -       | Raw base64 or data URL                          |
| `mimeType`      | string        | No       | -       | MIME type when sending raw base64               |
| `images`        | array         | No\*     | -       | Extra pages (`url` or `base64` each)            |
| `isHandwritten` | boolean       | No       | -       | Hint that the card is handwritten               |
| `skipReview`    | boolean       | No       | `false` | Publish immediately even when confidence is low |
| `cookbookId`    | string (UUID) | No       | -       | File the imported recipe in this cookbook       |

\*Provide `imageUrl`, `imageBase64`, or `images[]`.

## Output Schema

```typescript
{
  recipeId: string,
  status: "draft" | "needs_review" | "published",
  title: string,
  confidence: number,
  uncertainFields: string[],
  allergenClassifications: Array<{
    ingredientText: string,
    allergenCode: string,
    allergenName: string,
    relation: string
  }>,
  lowConfidenceFields?: string[],
  message: string
}
```

`uncertainFields` names values to check after a bad photo (`title`, `servings`, `times`, `ingredient: …`, `step N`). Extracted ingredient lines are classified with the existing allergen catalog (not per-person rules).

## Example Call (URL)

```json
{
  "imageUrl": "https://blob.vercel-storage.com/recipe-card.jpg"
}
```

## Example Call (base64, multi-page)

```json
{
  "imageBase64": "<page-1-base64>",
  "mimeType": "image/jpeg",
  "images": [{ "url": "https://blob.vercel-storage.com/page-2.jpg" }]
}
```

## Example Result (needs review)

```json
{
  "recipeId": "recipe-abc-123",
  "status": "needs_review",
  "title": "Something soup?",
  "confidence": 0.32,
  "uncertainFields": ["title", "servings", "times", "ingredient: [unclear line]", "step 1"],
  "message": "Recipe imported from photo but needs review. Uncertain: title, servings, times, ingredient: [unclear line], step 1"
}
```

## Notes

- Needs AI Gateway (`AI_GATEWAY_API_KEY` locally; OIDC on Vercel)
- Vision model: `RK_MODEL_VISION` or `deepseek/deepseek-v4.1-flash`
- Only the first photo is saved as the recipe image
- Prefer reviewing `uncertainFields` before cooking from a blurry card
