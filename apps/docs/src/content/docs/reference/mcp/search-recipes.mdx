Search for recipes with optional text query, method filters, and automatic safety checking for specified attendees. Returns recipes with inline warnings when potential allergen or dietary issues are detected.

## Input Schema

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `query` | string | No | - | Text search query (title, description, ingredients) |
| `forAttendees` | array of strings | No | - | Person IDs to check for blocking rules and annotate warnings |
| `methodTags` | array of strings | No | - | Filter by cooking method tags (e.g., "slow-cooker", "instant-pot") |
| `maxResults` | number | No | `20` | Maximum number of results to return (positive integer) |
| `cursor` | string | No | - | Pagination cursor from previous response |

## Output Schema

```typescript
{
  recipes: Array<{
    id: string,
    title: string,
    description?: string,
    prepTimeMinutes?: number,
    cookTimeMinutes?: number,
    servings?: number,
    methodTags: string[],
    images: string[],
    warnings?: Array<{
      personId: string,
      severity: "block" | "warn" | "prefer_avoid",
      message: string
    }>
  }>,
  nextCursor?: string
}
```

## Example Call

```json
{
  "query": "chicken pasta",
  "forAttendees": ["person-001", "person-002"],
  "methodTags": ["one-pot"],
  "maxResults": 10
}
```

## Filtering Behavior

### Safety Filtering

When `forAttendees` is provided:
- Recipes with **blocking** severity findings are filtered out automatically
- Recipes with **warn** or **prefer_avoid** findings are included with inline `warnings` annotations
- Each warning names the affected person and provides context

### Method Tags

When `methodTags` is provided:
- Only recipes matching at least one tag are returned
- Common tags: `slow-cooker`, `instant-pot`, `air-fryer`, `one-pot`, `sheet-pan`, `stovetop`, `oven`, `grill`, `no-cook`

### Text Search

When `query` is provided:
- Searches recipe title, description, and ingredient names
- Case-insensitive partial matching

## Pagination

- Use `maxResults` to control page size (default 20)
- If `nextCursor` is present, pass it back to get the next page
- Continue until `nextCursor` is absent

## Usage Notes

1. **Automatic safety filtering**: Recipes with blocking allergens for specified attendees are excluded from results
2. **Inline warnings**: Review `warnings` arrays to understand dietary considerations
3. **Get full details**: Use [get_recipe](/docs/reference/mcp/get-recipe) to see complete ingredient lists and nutrition
