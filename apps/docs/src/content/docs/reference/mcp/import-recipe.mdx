---
title: import_recipe
description: Import a recipe from a URL or pasted text
---

Import a recipe from a URL or pasted text. Pulls schema.org prep/cook times, servings, and the main image (copied into Vercel Blob). `save:false` returns a preview; omit `save` to persist. `skipReview` clears `needsReview`. `idempotencyKey` replays a save.

## Input

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `source` | `"url"` \| `"paste"` | Yes | - | Import source |
| `content` | string | No | - | URL or pasted recipe text. Required unless `draft` is sent |
| `draft` | object | No | - | Previewed recipe from a prior import. Skips extract |
| `save` | boolean | No | persist | `false` returns a preview without saving |
| `idempotencyKey` | string | No | - | Same key replays the same saved recipe |
| `allowDuplicate` | boolean | No | - | Persist even when this URL or draft already exists |
| `skipReview` | boolean | No | `false` | Skip review queue and publish immediately |
| `cookbookId` | string (UUID) | No | - | Optional cookbook to file the recipe in |

Classified import failures are JSON-RPC `-32602`. `import_ai_unavailable` is `-32603`.

## Example (preview)

```json
{
  "source": "url",
  "content": "https://example.com/recipes/chicken-pasta",
  "save": false
}
```

Send `save:true` with the returned `draft` to persist without extracting again.
