---
title: get_cookbook
description: Get a cookbook and the recipes filed in it
---

Returns one cookbook and its recipes, including servings, prep/cook times, and images.

## Input Schema

| Parameter | Type          | Required | Default | Description |
| --------- | ------------- | -------- | ------- | ----------- |
| `id`      | string (UUID) | Yes      | -       | Cookbook ID |
