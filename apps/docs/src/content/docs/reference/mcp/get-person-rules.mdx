---
title: get_person_rules
description: Get detailed dietary rules and restrictions for one or more people
---

Get comprehensive per-person rules including allergies, dietary restrictions, and preferences with severity levels and matching options. Use for detailed rule inspection and understanding safety requirements.

## Input Schema

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `personIds` | array of strings | Yes | - | Person IDs to get rules for (minimum 1) |
| `includeInactive` | boolean | No | `false` | Include rules outside their active date range |

## Output Schema

```typescript
{
  people: Array<{
    id: string,
    displayName: string,
    rules: Array<{
      id: string,
      kind: "allergen" | "ingredient" | "ingredient_category" | "diet" | "tag" | "custom",
      target: string,
      severity: "block" | "warn" | "prefer_avoid",
      label?: string,
      note?: string,
      options: {
        includeMayContain: boolean,
        includeCrossContact: boolean,
        sharedFacility: "block" | "warn" | "ignore",
        includeDescendants: boolean,
        treatCoconutAsTreeNut?: boolean
      }
    }>,
    labelNotes?: Array<{
      note: string,
      ingredientName?: string,
      category?: string
    }>
  }>
}
```

## Rule Types

### kind

- **allergen**: Named allergen from standard taxonomy (e.g., "peanuts", "tree_nuts", "dairy")
- **ingredient**: Specific ingredient name (e.g., "cilantro", "mushrooms")
- **ingredient_category**: Broad category (e.g., "red_meat", "seafood")
- **diet**: Dietary pattern (e.g., "vegetarian", "vegan", "kosher", "halal")
- **tag**: Recipe method or cuisine tag (e.g., "spicy", "fried")
- **custom**: Free-form custom rule with admin-defined matching

### severity

- **block**: Must not be present. For life-threatening allergies or strict religious/ethical restrictions
- **warn**: Should review before serving. For sensitivities or moderate preferences
- **prefer_avoid**: Soft preference. For dislikes or nutritional goals

### options

- **includeMayContain**: Match "may contain" warnings on packaged foods
- **includeCrossContact**: Match shared equipment warnings
- **sharedFacility**: How to handle "manufactured in a facility with..." warnings
- **includeDescendants**: For categories, match child ingredients (e.g., "tree nuts" matches "almonds")
- **treatCoconutAsTreeNut**: Special case for coconut allergy classification

## Example Call

```json
{
  "personIds": ["person-001", "person-002"],
  "includeInactive": false
}
```

## Usage Notes

1. **Safety labels**: The `label` field provides human-readable context (e.g., "Severe peanut allergy") for quick identification
2. **Active vs inactive**: By default, only currently active rules are returned; use `includeInactive: true` to see historical or future rules
3. **Rule matching**: The `options` control how strictly each rule is matched during checking
4. **Bulk lookup**: Pass multiple person IDs to minimize round trips when planning meals for a group
