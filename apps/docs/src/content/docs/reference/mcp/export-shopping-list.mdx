Export a shopping list for a saved meal plan with automatic ingredient aggregation, unit conversion, and per-person rule warnings. Supports multiple export formats for different use cases.

## Input Schema

| Parameter             | Type          | Required | Default      | Description                                                 |
| --------------------- | ------------- | -------- | ------------ | ----------------------------------------------------------- |
| `planId`              | string (UUID) | Yes      | -            | Meal plan ID to generate shopping list for                  |
| `format`              | enum          | No       | `"markdown"` | Output format: `"json"`, `"csv"`, `"markdown"`, or `"text"` |
| `groupBy`             | enum          | No       | `"aisle"`    | Grouping strategy: `"aisle"`, `"recipe"`, or `"category"`   |
| `includePantryItems`  | boolean       | No       | `false`      | Include pantry staples (salt, pepper, oil, etc.)            |
| `includeRuleWarnings` | boolean       | No       | `true`       | Include per-person rule warnings for shoppers               |

## Output Schema

```typescript
{
  format: string,
  content: string,
  itemCount: number,
  warnings: Array<{
    ingredient: string,
    personName: string,
    note: string
  }>
}
```

## Format Examples

### Markdown (default)

```markdown
# Shopping List

## Produce

- 2 cup cherry tomatoes (Grilled Chicken Salad)
- 1 head romaine lettuce (Grilled Chicken Salad)

## Meat

- 2 lb chicken breast (Grilled Chicken Salad)

## Grains

- 1 lb pasta (Vegetarian Pasta Primavera)

## Dairy

- 0.5 cup parmesan cheese (Vegetarian Pasta Primavera)

## ⚠️ Warnings

- **Child B**: parmesan cheese - Contains dairy (lactose intolerant preference)
```

## Grouping Strategies

### aisle

- Groups by grocery store aisle (produce, dairy, meat, etc.)
- Best for efficient shopping
- Pantry staples land in a **Pantry staples** section when `includePantryItems` is true

### recipe

- Groups by recipe
- Helps with recipe-by-recipe shopping
- Good for meal kit-style shopping

### category

- Groups by ingredient category (produce, dairy, grains, etc.)
- Balanced between organization and flexibility
- Uses the same aisle map as `groupBy=aisle`

## Usage Notes

1. **Automatic aggregation**: Duplicate ingredients across recipes are combined when possible
2. **Unit conversion**: Common unit conversions are applied (e.g., 3 tsp = 1 tbsp)
3. **Safety warnings**: Inline warnings alert shoppers to dietary restrictions and allergens
4. **Pantry items**: Enable `includePantryItems: true` to include staples like salt and oil
5. **Parse confidence**: Low-confidence parsed ingredients may show in `rawText` form
