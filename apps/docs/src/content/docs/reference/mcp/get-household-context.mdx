---
title: get_household_context
description: Get household schedule, people, rules, preferences, and recent meal history
---

Get comprehensive household context including weekly schedule, member information with rule summaries, preferences, and recent meal history. Essential starting point for meal planning.

## Input Schema

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `includeSchedule` | boolean | No | `true` | Include weekly schedule template and overrides |
| `includePeople` | boolean | No | `true` | Include household members with rule summaries |
| `includePreferences` | boolean | No | `true` | Include household cuisine preferences and avoidances |
| `includeRecentMeals` | boolean | No | `true` | Include recent meal history |

## Output Schema

```typescript
{
  household: {
    id: string,
    name: string,
    servingsSettings: {
      mode: "family" | "fixed" | "recipe",
      servings: number | null,
      familySize: number,
      defaultCookFor: number
    }
  },
  schedule?: {
    weeklyTemplate: Array<{
      day: string,
      meal: string,
      busyLevel: "low" | "medium" | "high",
      timeBudgetMinutes?: number,
      cooking: boolean,
      attendees: string[],
      constraints: string[]
    }>,
    overrides: Array<{
      date: string,
      meal: string,
      note: string
    }>
  },
  people?: Array<{
    id: string,
    displayName: string,
    age?: number,
    activityProfile?: string,
    rulesSummary: {
      blockCount: number,
      warnCount: number,
      preferAvoidCount: number
    },
    labelNotes?: string[]
  }>,
  preferences?: {
    cuisines: string[],
    avoidances: string[]
  },
  recentMeals?: Array<{
    date: string,
    meal: string,
    recipeTitle: string
  }>
}
```

## Example Call

```json
{
  "includeSchedule": true,
  "includePeople": true,
  "includePreferences": true,
  "includeRecentMeals": true
}
```

## Usage Notes

1. **Start with context**: Call this tool at the beginning of meal planning sessions to understand household needs
2. **Rule summaries**: The `rulesSummary` provides quick counts; use [get_person_rules](/docs/reference/mcp/get-person-rules) for full rule details
3. **Activity profiles**: Use activity levels to estimate caloric needs when selecting recipes
4. **Label notes**: Quick-reference labels (e.g., "Severe peanut allergy") for safety-critical information
