---
title: get_household_context
description: Household schedule, people, rules, preferences, and recent meals
---

Get household context including Default servings (family size, mode, cook-for), schedule, attendees, rule summaries, preferences, and recent meal history. People include `sortOrder` and `loves` (never used to hide recipes). Essential for meal planning. Not medical advice - always check ingredient labels before serving.

## Input

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `includeSchedule` | boolean | No | `true` | Weekly schedule |
| `includePeople` | boolean | No | `true` | People with rule summaries and Loves |
| `includePreferences` | boolean | No | `true` | Cuisine preferences, avoidances, and Loves |
| `includeRecentMeals` | boolean | No | `true` | Recent meal history |

## Example

```json
{
  "includeSchedule": true,
  "includePeople": true
}
```

Call `whoami` first if you need to confirm the kitchen. Use [get_person_rules](/docs/reference/mcp/get-person-rules) for full rule rows.
