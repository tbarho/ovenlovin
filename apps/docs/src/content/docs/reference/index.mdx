## MCP Tools

Model Context Protocol tools for AI agents to interact with OvenLovin.

### Planning Tools
- [get_household_context](/docs/reference/mcp/get-household-context) - Get household schedule and member information
- [search_recipes](/docs/reference/mcp/search-recipes) - Find recipes with safety checks
- [get_recipe](/docs/reference/mcp/get-recipe) - Get detailed recipe information

### Safety & Checking
- [check_meal_plan](/docs/reference/mcp/check-meal-plan) - **Safety-critical** rule checking
- [get_person_rules](/docs/reference/mcp/get-person-rules) - Get detailed dietary rules

### Meal Management
- [save_meal_plan](/docs/reference/mcp/save-meal-plan) - Save a meal plan
- [get_meal_plan](/docs/reference/mcp/get-meal-plan) - Retrieve a saved plan
- [export_shopping_list](/docs/reference/mcp/export-shopping-list) - Generate shopping lists

### Import
- [import_recipe](/docs/reference/mcp/import-recipe) - Import from URL or text
