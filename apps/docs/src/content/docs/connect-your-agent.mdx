# Connect your agent

OvenLovin speaks **MCP** (Streamable HTTP at `/mcp`) and **REST** (`/api/v1`, OpenAPI at `/api/v1/openapi.json`).

Deploy your own copy (Deploy button), sign in, open Settings, then API keys, create a key, and copy the `plaintext` value (shown once). Call `https://<your-app>.vercel.app/api/v1` with `Authorization: ApiKey rkapi_...` and connect MCP at `https://<your-app>.vercel.app/mcp`.

Just looking? The public demo at https://ovenlovin-demo.vercel.app issues a 24h sandbox key at /api/demo/enter?format=json.

`Bearer rkapi_...` is accepted too.

This is not medical advice. Always check ingredient labels before serving.

## Claude Code

```bash
claude mcp add --transport http ovenlovin https://<your-app>.vercel.app/mcp \
  --header "Authorization: ApiKey YOUR_OVENLOVIN_API_KEY"
```

## Claude Desktop

macOS/Linux: `~/Library/Application Support/Claude/claude_desktop_config.json`  
Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "ovenlovin": {
      "url": "https://<your-app>.vercel.app/mcp",
      "headers": {
        "Authorization": "ApiKey YOUR_OVENLOVIN_API_KEY"
      }
    }
  }
}
```

Restart Claude, then ask it to call `whoami` and `get_household_context`.

## ChatGPT (Custom GPT Actions)

1. GPT builder → Actions → Import from URL: `https://<your-app>.vercel.app/api/v1/openapi.json`
2. Authentication: API Key
3. Header name: `Authorization`
4. Value: `ApiKey YOUR_OVENLOVIN_API_KEY` (include the `ApiKey` prefix)

## Grok

```json
{
  "mcpServers": {
    "ovenlovin": {
      "transport": "http",
      "url": "https://<your-app>.vercel.app/mcp",
      "headers": {
        "Authorization": "ApiKey YOUR_OVENLOVIN_API_KEY"
      }
    }
  }
}
```
