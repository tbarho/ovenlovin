# @ovenlovin/brand

Shared OvenLovin logo, wordmark, and favicon.

The mark is a small illustrated oven — a single food object in the same spirit as [barrito](https://tbarho.github.io/barrito/) — with warm terracotta, a glowing window, and a loaf inside.

## Assets

| File | Use |
| --- | --- |
| `assets/mark.svg` | Logo mark on light backgrounds |
| `assets/mark-dark.svg` | Logo mark on dark backgrounds |
| `assets/wordmark.svg` | Wordmark on light backgrounds |
| `assets/wordmark-dark.svg` | Wordmark on dark backgrounds |
| `assets/logo.svg` | Mark + wordmark (light) |
| `assets/logo-dark.svg` | Mark + wordmark (dark) |
| `assets/favicon.svg` | App and docs favicon |

Served copies live at:

- `apps/web/public/brand/` — deployed app
- `apps/docs/public/brand/` — documentation site

Use the public paths from `brandPublicPath` (`/brand/mark.svg`, `/brand/logo.svg`, …) in the Next.js apps.
