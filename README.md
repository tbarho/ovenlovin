# recipe-kit

> ⚠️ **Pre-alpha — no app code yet.** The design spec lives in [issue #1](../../issues/1).

An LLM-native, bot-friendly recipe + family meal-planning template for Vercel (TypeScript). Designed as an asset that bot teams (Grok Bot, ChatGPT, Claude Code) can plug into via REST/OpenAPI, MCP, and a CLI.
